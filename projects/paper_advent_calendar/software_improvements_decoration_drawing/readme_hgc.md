goal is to create an advent calendar by first printing the papers with a normal color printer. then cut the cuts. 
the challange is to exactly align the print with the cut. 

the software should allow to load an image. 

the boundary has to be smaller than a4 , even smaller than the maximum print size of the a4 printer. 

the distance to the boundary of the advent calendar from the bottom left corner  has to be set exactly the same in the software and in the paper cutting software (bambu suite)

the software should allow printing the image with the exact set distances so not scaling or added border margins by the color printer should be done.

after the image is loaded in the software , there should be some image editor functions, that might help positioning the image (crop , transform, resize and so on)
