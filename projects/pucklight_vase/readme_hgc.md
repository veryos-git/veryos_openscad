goal of this project is a small webapp that can be used to create a fdm printable pucklight. the sockel and clickbase is already existing and can be taken or reconstructed from pucklight_lantern3 . 

the webapp should be able to do the following. 

the user is expected to be a programmer that has basic knowledge of mathematics. 

in principle the top of the light object will be generated by looping over z layers and then looping over corners of a regular polygon for example. 

the position of the verticies can be defined by changing a source code in a monaco editor. 

however the generated solid should start with a thread, that fits to the sockel and can be screwed in. those verticies are not manipulated by the callback function. 

the application to create a vase by programming already has been created , take inspiration from it and also take some good example callback functions. 

but do not get restricted by it, goal is not to  make the app 1:1 like the 'stlsculpter'
