goal: a webapp that can be used to create digital files required for producing a paper advent calendar.


the calendar will be produced out of 250g a4 cardstock paper. 

it will have two layers. 
- back: this layer has only some cuts that one can see where the window openings will be 
- front: this layer has cuts that make up intended breaking points and intended folding lines

the machine used to create the calendar

numbers and images on the windows are not required , they are being drawed after the papers are cut!



see /home/mintuser/code/veryos_openscad/projects/paper_advent_calendar/idea_veryos.jpeg

the webapp should have parameters to control:
    - size of calendar (default A4 290x210mm)
    - number of windows (default 24)
    - variantions of windows    
        - placement of individual windows. 


the webapp should provide a print functionality so that the a4 front and back can be printed to get a feeling of the calendar before cutting it on paper. 


cutting:
    a paper cutting machine will be used to cut the papers. 
    the blade can do quite fine details. the software requires svg files, so the webapp should export svg files
