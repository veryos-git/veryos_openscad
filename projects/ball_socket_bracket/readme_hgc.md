this openscad script can generate a ball and socket joint that can be locked with a screw, optimized for fdm printing. ball and socket both have mounting plates
parts are: 

    ball with mounting plate
    socket with mounting plate
    screw


the screw should be a fitting diameter (fdm printing optimized screw , see other project 'optimized screws')

the printing orientation of the ball should be vertical so that the extrusion lines are as long as possible
