listing.md contains the listing title, description and tags.
parameters.json records the defaults used for every annotated image.
model/ contains the corresponding SCAD source, print-oriented STLs and license.
contact-sheet.jpg reviews the original nine rendered images.
veryos_screw_top_container_upload_pack.zip bundles the eleven JPEGs, this guide,
listing copy, parameter values and model files. PNG masters remain outside
the ZIP in the images folder.

The images use the current source's 2.0 mm thread pitch. At 0.2 mm shoulder
extrusion, the estimated stopping-angle change is 36 degrees and the closed
height is 80.2 mm. Physical print fit has not been tested.

Rendering
The model geometry is exported directly from OpenSCAD and rendered in Blender.
Annotations are projected from known geometry points and typeset separately.
Colors are illustrative. Cutaways are explanatory views, not printable parts.
The supplied STLs are the complete base and lid.

Regeneration from the repository root
  node projects/simple_cylindrical_screwing_container/publish/source/render.mjs

Requirements: Node.js, bundled OpenSCAD AppImage, Blender, Python 3, Pillow,
NumPy, PyGObject/Rsvg and Pycairo. The layout is designed for this preset;
review label placement if the model dimensions are changed substantially.
The raw render cache is in .gitignored/container_listing.

Artwork uses the original veryos_logo.svg and the OpenSCAD icon bundled with
OpenSCAD. Typography is DejaVu Sans Mono, the available monospace fallback
because Consolas was not installed on the rendering host.
