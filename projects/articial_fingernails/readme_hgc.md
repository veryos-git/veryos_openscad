the goal is to create a simple articial fingernail / finger adapter / 'aufsatz' that can be sticked onto the fingers. 

there is already a good model in the inspiration folder. the goal is now to reverse engeneer it and create a openscad script that can create the base model out of primives. the base model should NOT be exactly same as the original model, it should only provide a basic functional starting point part that then can be decorated with a sculpting software !
