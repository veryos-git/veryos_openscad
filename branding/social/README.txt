VeryOS social media assets
=========================

Four coordinated variants: graphite, ivory, amber, linework.

profile-*.png  1024 x 1024 px, with space for a circular profile crop.
banner-*.png   2400 x 800 px, general-purpose 3:1 banners.
*.svg         Scalable vector originals with outlined lettering.
preview.png   Overview, including square and circular profile previews.

Banner wording: VeryOS / Very Open Source.

The original veryos_logo.svg paths are preserved. Color, background,
stroke treatment and composition distinguish the variants.
The graphite, ivory and amber profiles use a filled mark; linework uses
the same paths with a contrasting outline. Graphite is the recommended
starting point for small profile images.

Typography: DejaVu Sans Bold for VeryOS; DejaVu Sans Mono for the slogan.
Lettering is converted to vector paths, so no fonts are required to use
the SVGs. PNGs have opaque backgrounds for predictable appearance.

These are general-purpose assets, not platform-specific safe-area templates.
Check each service's crop preview when uploading a banner.

Artwork is derived directly from the repository's vector logo.
No AI-generated reconstruction of the mark or lettering was used.
