a very openscad script that can create a very simple and basic turntable for the 28byj stepper motor. customizable 

the stepper motor directly drives the platform, no gears involved
the hardware should be fdm printable 

inspiration/ folder shows a possible way to solve the hardware problem. 

the speed of the stepper motor can be set via esp32 software: 
software requirements: 
    esp32 exposes a open wifi with no password and hosts a website with a very simple ui for the speed and more optional settings


a simple small interactive denojs script or a tiny webapp that can be used to flash the connected esp32 is also required.
