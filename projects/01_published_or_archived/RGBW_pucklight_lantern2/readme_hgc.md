this project is a openscad script that allows to generate the parts for a 3d printable lantern. 

parts: 
    - roof
    - frame
    - screwin
    - clickbase

the lantern uses a RGBW pucklight at the bottom. the openscad source code from /home/legion5pro/code/veryos_openscad/projects/RGBW_pucklight_holder has to be derived to generate the pucklight holder


description of the lantern. 
the pucklight can be screwed in in the bottom of the frame. 
the roof can be screwed onto the top of the frame 
the sides of the frame have kind of 'slits' to slide in side windows



the openscad script has to work as a standalone script so that it runs in a browser openscad interpretor / live openscad preview webapp
